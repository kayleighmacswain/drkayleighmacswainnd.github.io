## Deploying to GitHub Pages
1. Create a GitHub repo (e.g. `drkayleighmacswainnd`)
2. Push all files to the `main` branch
3. Go to Settings → Pages → Source: Deploy from branch → `main` / `/ (root)`
4. Your site will be live at `https://<yourusername>.github.io/drkayleighmacswainnd/`
